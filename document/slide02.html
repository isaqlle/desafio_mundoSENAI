Arquitetura do Projeto Visão Geral

Este projeto é dividido em duas partes principais: Frontend e Backend. O Frontend é a interface que o usuário vê e interage, enquanto o Backend é responsável por processar as regras e lógica do sistema de forma invisível.

Instrutor: Isaque Pontes

A Arquitetura do Projeto Visão Geral

  • Conceito: Todo software moderno é dividido em partes fundamentais (Frontend e Backend).
  • No nosso projeto: O visitante do evento não vê tudo; ele interage apenas com a "casca", enquanto o "cérebro" processa as regras de cada uma das 4 estações de forma invisível.

Frontend O Rosto do Sistema

  • O que é: O HTML cria o "esqueleto" (botões, textos) e o CSS aplica o estilo visual (cores, tamanhos e alinhamentos).
  • Por que usamos no projeto? É fundamental para a Estação 1 (UX e Requisitos). O visitante precisa entender conceitos de contraste e interface amigável. É o HTML/CSS que permite validar se o botão ou a cor de fundo estão acessíveis.

Backend O Cérebro

  • O que é: Python é a linguagem de programação principal, e o Flask (na versão 3.1.0) é o framework que cria o servidor.
  • Por que usamos no projeto? O Python e o Flask recebem as ações do usuário através de rotas (como /api/ux/check ou /api/logica/check) e executam validações e regras no backend antes de devolver a resposta visual para a tela.

Lógica de Sistemas Python na Prática

  • O que é: O uso de estruturas condicionais lógicas (if, else, ==).
  • Por que usamos no projeto? Na Estação 2 (Lógica de Sistemas), o sistema precisa avaliar uma sequência de decisões (como validar crachá, turno e EPI) para liberar ou bloquear o acesso do funcionário.

Modelagem de Dados e Banco Python + SQLite

  • O que é: O uso de Dicionários em Python (listas de dados em pares) e integração com banco de dados SQLite (sqlite3).
  • Por que usamos no projeto? Na Estação 3 (Modelagem de Dados), precisamos organizar as informações de forma limpa, associando nomes a categorias específicas (ex: "Ana Souza" é identificada como funcionário, "Robô R-07" é identificado como máquina).

Pesquise os Conceitos e um exemplo prático de utilização

  • Frontend: HTML, CSS, JavaScript, React, Angular.
  • Backend: Python, Flask, Django, Node.js.
  • Lógica de Sistemas: Estruturas condicionais, operadores lógicos, fluxogramas.
  • Modelagem de Dados e Banco: Dicionários em Python, SQLite, MySQL, PostgreSQL.
